# 🛠️ Универсальный движок развертывания инфраструктуры (Deploy Engine)

Легковесный, гибкий и полностью независимый инструмент в концепции **Infrastructure-as-Code (IaC)**, написанный на Python. Движок позволяет декларативно управлять, синхронизировать и развертывать системные службы `systemd` (сервисы и таймеры), исполняемые скрипты, символьные ссылки и конфигурационные файлы в Linux-системах с помощью простых JSON-манифестов.

Этот репозиторий содержит исключительно логику деплоера и полностью отделен от ваших приватных конфигурационных данных, скриптов или секретов, что делает его безопасным для использования в Open Source.

## ✨ Ключевые возможности

- **Полное разделение кода и данных (Decoupled)**: Движок не содержит захардкоженных путей или названий серверов. Он работает как абстрактный оркестратор, принимая путь к внешнему `manifest.json` в качестве аргумента.
- **Рекурсивные манифесты (`includes`)**: Позволяет разбивать конфигурацию огромной инфраструктуры на цепочки («матрешки») мелких атомарных микропакетов. Манифесты могут ссылаться друг на друга через относительные пути.
- **Поддержка символьных ссылок (`symlinks`)**: Умеет атомарно создавать системные мягкие ссылки (`ln -sf`), избавляя от необходимости копировать тяжелые папки с кодом и позволяя выводить утилиты в глобальный `/usr/local/bin`.
- **Шаблонизация кода и путей на лету**: Перед установкой текстовых файлов движок сканирует их содержимое и заменяет маркеры `{{BASE_DIR}}`, `{{SYS_BIN}}`, `{{SYS_SYSTEMD}}` и динамический корень проекта **`{{ROOT_DIR}}`** на реальные абсолютные пути.
- **Умное управление `root_dir`**: По умолчанию `{{ROOT_DIR}}` вычисляется автоматически как папка на уровень выше манифеста. Вы можете жестко переопределить это поведение для конкретного юнита в JSON, указав относительный откат (`"root_dir": ".."`) или абсолютный системный путь (`"root_dir": "/opt/..."`).
- **Автозагрузка через `packages.json`**: Запуск TUI и CLI без аргументов автоматически подтягивает локальный реестр манифестов, избавляя от необходимости вводить длинные абсолютные пути в терминале.
- **Два режима работы на выбор**:
  - **Продвинутый графический интерфейс (TUI)**: Интерактивное дерево пакетов на базе библиотеки `Textual`, поддерживающее навигацию стрелками и мгновенный рендеринг путей.
  - **Быстрый CLI-режим**: Легковесный запуск на чистом Python без внешних зависимостей. Идеально подходит для фоновых задач, cron-таймеров или CI/CD пайплайнов.

## 📁 Структура репозитория

```text
deploy-engine/
├── .gitignore            # Защита репозитория от кэша Python (__pycache__) и виртуального окружения
├── LICENSE               # Лицензия Apache 2.0
├── README.md             # Документация проекта (этот файл)
├── deploy_config.py      # Глобальные системные пути по умолчанию (например, /usr/local/bin)
├── deploy.py             # Точка входа для быстрого CLI-бэкенда (чистый Python)
├── deploy_ui.py          # Точка входа для интерактивного TUI-фронтенда (стартер виртуального окружения)
└── lib/
    ├── __init__.py       # Маркер пакета модулей Python
    ├── engine.py         # Ядро деплоера: рекурсивный парсинг JSON, сбор зависимостей, симлинки и шаблонизация
    ├── ui_app.py         # Логика интерфейса Textual: отрисовка дерева и динамический лог путей/ссылок
    └── utils.py          # Служебные утилиты: проверка прав root и автоматический бутстрап .venv
```

## 🚀 Инструкция по использованию

Для работы деплоера необходимо запустить его через `sudo` и передать ему путь к вашему целевому файлу манифеста.

### 1. Интерактивный режим (TUI)
```bash
sudo ./deploy_ui.py /путь/к/вашей/инфраструктуре/manifest.json
```

### 2. Тихий консольный режим (CLI)
```bash
sudo ./deploy.py /путь/к/вашей/инфраструктуре/manifest.json full-node-setup
```

## 📄 Спецификация JSON-манифеста с поддержкой Symlinks и Root_Dir

```json
{
  "units": {
    "amnezia-stat.py": {
      "type": "script",
      "desc": "Скрипт фонового демона статистики",
      "root_dir": ".."
    },
    "cli-link": {
      "type": "symlink",
      "desc": "Системный симлинк на корень всего проекта",
      "src": "{{ROOT_DIR}}",
      "dest": "/opt/vnikolay-cli"
    },
    "amnstat-bin-link": {
      "type": "symlink",
      "desc": "Глобальный ярлык для вызова утилиты из терминала",
      "src": "{{ROOT_DIR}}/cli/show_stats.py",
      "dest": "/usr/local/bin/amnstat"
    }
  }
}
```
