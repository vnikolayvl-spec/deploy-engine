# 🔧 Deploy Engine (версия 9.0.0)

**Deploy Engine** — модульный, кроссплатформенный и автономный оркестратор развертывания инфраструктуры в концепции **Infrastructure-as-Code (IaC)** на Python.

Движок позволяет декларативно управлять системными службами (`systemd` в Linux и `launchd` `.plist` в macOS), исполняемыми скриптами, конфигурационными файлами, директориями, правами доступа, постоянными динамическими данными (базами данных), резервными копиями и защищенными переменными окружения с помощью JSON-манифестов (`manifest.json` и `category.json`).

---

## ✨ Ключевые возможности

- **Единая точка входа (`files/main.py`)**:
  - Запуск без CLI-команды (или с флагом `--tui` / `-u`) открывает интерактивный графический TUI-интерфейс.
  - Запуск с командой (`install`, `uninstall`, `reinstall`, `backup`, `restore`, `list`, `info`, `scan`, `help`) или флагом `--info` (`-i`) работает в CLI-режиме.
  - Корректный перехват `Ctrl+C` (`KeyboardInterrupt`) на любом этапе с автоматическим откатом незавершенной транзакции в обратном порядке (`LIFO`).
- **Алиасы по имени папки, автопоиск каталогов и фильтрация шаблонов**:
  - Автоматический поиск репозитория пакетов по трем стандартным названиям: `packages`, `deploy-packages`, `deploy_packages`.
  - Автоматическая регистрация алиасов как по каноническому имени пакета, так и по имени его папки на диске (например, `vpn-server/amneziawg` и `amneziawg` -> `vpn-server/awg`).
  - Автоматическое игнорирование шаблонных и служебных директорий с префиксом `_` (`_template-py`, `_template-ts`).
- **Интеллектуальный кэш метаданных (`packages.json`)**:
  - При запуске структура пакетов мгновенно считывается из кэша, если возраст кэша не превышает **60 минут** и файлы манифестов не изменялись.
  - Команда `scan` или флаг `--rescan` принудительно переобходят файловую систему и обновляют кэш.
- **Сохранение пути к манифесту в `state.json` и приоритет манифестов**:
  - При установке каждого пакета в `/etc/default/state.json` сохраняется абсолютный путь к его `manifest.json` (`manifest_path`).
  - Установленные пакеты вне текущего манифеста догружаются с пометкой `(внешний)` (полная функциональность) или `! (манифест удален)` (управление службой и просмотр логов).
- **Потоковое логирование операций (`install_DATE.log`)**:
  - Построчный потоковый вывод (`stdout` + `stderr`) пакетных менеджеров (`apt-get`, `dnf`, `apk`, `pacman`, `brew`), `pip`, `npm` и хуков в реальном времени в окно TUI и в `/var/lib/de_<pkg>/install_YYYYMMDD_HHMMSS.log`.
- **Хранилище постоянных динамических данных (`data`) и неразрушающий `.env` (`EnvUpsertManager`)**:
  - Юниты `data` (`/var/lib/de_<pkg>/`) никогда не перезаписываются при обновлении или переустановке.
  - Юниты `env` (`/etc/default/de_<pkg>/<pkg>.env`) дополняются только новыми ключами без затирания существующих секретов (сброс только по `--clean-env`).

## 💻 Графический TUI-интерфейс (Textual)

Трехколоночный интерфейс на всю высоту терминала (все иконки подобраны со строгой шириной `East_Asian_Width=W` для идеального выравнивания рамок в macOS Terminal и iTerm2):

1. **Левая колонка — единый список пакетов (`📦 Пакеты`)**:
   - Отображает пакеты с запланированными действиями, их **транзитивные зависимости** (с пометкой `(зависимость)`) и уже установленные в системе пакеты.
   - Пакеты с действиями и их зависимости всегда выводятся вверху списка (`+` установка, `↻` переустановка, `-` удаление, `💾` бэкап, `🔄` восстановление).
   - **Клик или нажатие `Enter`** на пакете открывает модальное окно **карточки пакета (`PackageDetailsModal`)** с вкладками `📋 Информация`, `📜 Лог установки`, `🔧 Логи службы` и кнопками управления службой/пакетом.
2. **Центральная колонка — дерево пакетов и предпросмотр плана**:
   - Установленные пакеты содержат вложенный пункт **«💾 Создать бэкап»** и список **«🔄 Восстановить из бэкапа»**.
3. **Правая колонка — настройки Sandbox и выполнение в TUI (`ExecutionModal`)**:
   - Переключение режима песочницы (`Sandbox`) и целевой ОС (`debian`, `ubuntu`, `alpine`, `arch`, `fedora`, `macos`) на лету.
   - Нажатие **«Выполнить план»** открывает многовкладочное модальное окно **`ExecutionModal`**:
     - Вкладка **`📋 Общий лог`** и отдельные вкладки **`📦 <пакет>`** для каждого пакета в очереди установки (включая зависимости).
     - На вкладке каждого пакета с `.env` размещена встроенная компактная панель **`PackageEnvPanel`** (перекрывающая пустой лог до подтверждения).
     - Если в `.env` есть промпты без дефолтного значения (`[❗ ОБЯЗАТЕЛЬНО]`), кнопка **`✅ Принять .env`** заблокирована до их заполнения.
     - Во время длительных операций (например, `apt-get update`) можно переключаться по вкладкам пакетов, копировать данные из логов уже установленных пакетов и заранее принимать `.env`. Когда очередь установки доходит до пакета с еще не подтвержденным `.env`, окно автоматически переключает фокус на его вкладку и ждет подтверждения.
     - После подтверждения значения сохраняются одновременно в `deploy-engine/env/<pkg>.env` и в целевой `/etc/default/de_<pkg>/<pkg>.env`, а панель `.env` сворачивается/скрывается, открывая лог пакета на всю высоту вкладки.
4. **Универсальная поддержка русских хоткеев (`RU <-> EN`)**:
   - Двойное нажатие **`q-q`** или **`й-й`** в течение 1 секунды — выход из TUI.
   - Клавиша **`e`** или **`у`** — открытие компактного редактора `.env` для выбранного пакета.

## 🔑 Команды и ключи запуска CLI / TUI

### Позиционные команды (`pos_args`)

| Команда | Назначение |
| :--- | :--- |
| *(без команды)* / `tui` | Запуск интерактивного трехколоночного TUI-интерфейса |
| `install <пакет...>` | Транзакционная установка указанных пакетов и их зависимостей |
| `reinstall <пакет...>` | Полная переустановка пакетов с сохранением `data` и `.env` |
| `uninstall <пакет...>` | Удаление пакетов с авто-остановкой служб (сохраняет `data` и `.env` без `--purge`) |
| `backup <пакет\|all>` | Создание архива резервной копии данных и `.env` пакета |
| `restore <пакет\|all> [N]` | Восстановление данных и `.env` пакета из архива бэкапа |
| `list` | Вывод таблицы (или JSON) установленных в системе пакетов |
| `info <пакет...>` | Подробная информация о пакете, категории, статусе и путях файлов |
| `scan` | Принудительное пересканирование директорий пакетов и обновление `packages.json` |
| `help` | Вывод справки по командам и ключам запуска |

### Ключи (флаги) запуска

| Ключ | Аргумент | Описание |
| :--- | :--- | :--- |
| `--tui`, `-u` | — | Принудительно открыть интерактивный TUI-интерфейс |
| `--info`, `-i` | `[ПАКЕТ]` | Показать описание пакета, статус и пути установки |
| `--manifest`, `-m` | `<ПУТЬ>` | Путь к `manifest.json` пакета или к корневой папке дерева пакетов |
| `--packages-dir`, `-d` | `<ПУТЬ>` | Путь к папке-источнику дерева пакетов |
| `--comment`, `-c` | `<ТЕКСТ>` | Комментарий к создаваемому бэкапу (для команды `backup`) |
| `--backup`, `-b` | `<СЕЛЕКТОР>` | Номер (`1`, `2`...), метка времени или имя архива для команды `restore` |
| `--list`, `-l` | — | Показать список доступных резервных копий (для `backup` и `restore`) |
| `--sandbox` | `[ОС]` | Тестовый режим песочницы (`debian`, `ubuntu`, `alpine`, `arch`, `fedora`, `macos`) |
| `--sandbox-dir` | `<ПУТЬ>` | Путь к директории локальной песочницы (по умолчанию `./.de_sandbox`) |
| `--dry-run`, `-n` | — | Симуляция выполнения операций без модификации файловой системы |
| `--purge` | — | Полное удаление каталогов `ENV` и `Data` при удалении пакета (`uninstall`) |
| `--clean-env` | — | Сброс переменных окружения `.env` к заводским значениям из шаблона при установке |
| `--rescan` | — | Принудительный переобход директорий пакетов и обновление кэша `packages.json` |
| `--remote`, `-r` | `<ХОСТ>` | Выполнение команды или TUI на удаленном сервере по SSH (`[user@]host[:port]`) |
| `--remote-dir` | `<ПУТЬ>` | Путь к `deploy-engine` на удаленном сервере (по умолчанию `/opt/de_deploy-engine`) |
| `--config` | `<ФАЙЛ>` | Путь к пользовательскому `.env`-файлу конфигурации самого движка |
| `--yes`, `-y` | — | Неинтерактивный режим CLI (использовать дефолтные значения `.env` без запросов) |
| `--json` | — | Вывод результатов (`list`, `info`, `backup`, `restore`) в формате JSON |
| `--verbose`, `-v` | — | Подробный отладочный вывод всех файловых и системных операций |

## 🌐 Переменные окружения (ENV)

Конфигурация движка загружается иерархически (`lib/config.py`):
`os.environ` -> `--config <файл>` / `DE_CONFIG_FILE` -> `/etc/default/de_deploy-engine/deploy-engine.env` -> `files/app.env` -> встроенные значения по умолчанию.

| Переменная ENV | Значение по умолчанию (system / local) | Описание |
| :--- | :--- | :--- |
| `DE_CONFIG_FILE` | `""` | Путь к кастомному файлу конфигурации движка (альтернатива ключу `--config`) |
| `DE_NONINTERACTIVE` | `""` (`1` / `true`) | Отключение интерактивных запросов `/dev/tty` в CLI (аналог флага `--yes`) |
| `DE_DATA_DIR` | `/var/lib/de_deploy-engine` | Базовый каталог данных установленного в систему движка |
| `DE_PACKAGES_DIR` | `/var/lib/de_deploy-engine/packages` (или `./packages`) | Каталог поиска пакетов по умолчанию |
| `DE_PACKAGES_CACHE` | `/var/lib/de_deploy-engine/packages.json` (или `./packages.json`) | Путь к файлу кэша проиндексированных манифестов |
| `DE_LOCAL_ENV_DIR` | `/var/lib/de_deploy-engine/env` (или `./env`) | Каталог сохранения пользовательских пресетов `.env` (`<pkg>.env`) |
| `DE_BACKUP_DIR` | `/var/lib/de_deploy-engine/backup` (или `./backup`) | Каталог хранения архивов резервных копий пакетов |
| `DE_REMOTE_ENGINE_DIR` | `/opt/de_deploy-engine` | Путь к установленному `deploy-engine` на удаленном сервере для режима `--remote` |
| `DE_SYS_BIN` | `/usr/local/bin` | Системный каталог для установки исполняемых скриптов (`type: "script"`) и симлинков |
| `DE_SYS_SYSTEMD` | `/etc/systemd/system` | Системный каталог для установки юнитов `systemd` (`.service`, `.timer`) |
| `DE_ENV_PATH` | `/etc/default` | Базовый системный каталог для хранения секретов пакетов (`/etc/default/de_<pkg>/`) |
| `DE_STATE_DIR` | `/var/lib` | Базовый системный каталог для постоянных данных пакетов (`/var/lib/de_<pkg>/`) |
| `DE_VENV_PATH` | `/opt/de_deploy-engine/files/.venv` (или `./.venv`) | Путь к виртуальному окружению Python для TUI (`Textual`) и зависимостей |

## 🚀 Примеры использования

```bash
# Запуск интерактивного TUI
python3 deploy-engine/files/main.py
python3 deploy-engine/files/main.py ./deploy-packages --sandbox macos

# Сканирование базы пакетов и инспекция
python3 deploy-engine/files/main.py scan -d ./deploy-packages
python3 deploy-engine/files/main.py list
python3 deploy-engine/files/main.py info local-tools/ssh-profile

# Установка, переустановка и удаление в CLI
sudo python3 deploy-engine/files/main.py install local-tools/server-bootstrap --yes
sudo python3 deploy-engine/files/main.py reinstall local-tools/ssh-profile
sudo python3 deploy-engine/files/main.py uninstall local-tools/server-bootstrap --purge

# Резервное копирование и восстановление
python3 deploy-engine/files/main.py backup all -c "Перед обновлением"
python3 deploy-engine/files/main.py backup --list
sudo python3 deploy-engine/files/main.py restore my-service 1

# Удаленное управление по SSH (CLI и Remote TUI)
python3 deploy-engine/files/main.py list --remote admin@10.0.0.5
python3 deploy-engine/files/main.py --tui --remote admin@10.0.0.5
```
